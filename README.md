# عيادة دكتورة ميس للتغذية — نظام متابعة المراجعين

نظام متكامل لعيادة تغذية (Nutrition Clinic) بواجهتين منفصلتين:
- **واجهة المريض**: تعبئة استمارة التقييم، عرض الخطة الغذائية، متابعة تطور الوزن.
- **واجهة الطبيب**: قائمة المراجعين، عرض/تعديل استمارة كل مريض، وضع الخطة الغذائية، تسجيل زيارات المتابعة، وكتابة ملاحظات.

النظام مبني اعتماداً على استمارة "متابعة المراجعين" التي زودتني بها (صفحة التقييم الأساسي + صفحة التغذية والخطة والمتابعة).

## التقنيات
- **Backend**: Python (Django + Django REST Framework + SimpleJWT + SQLite) — REST API مع تسجيل دخول JWT وصلاحيات (مريض / طبيب).
- **Frontend**: HTML + CSS + JavaScript خام (بدون أي إطار عمل)، بتصميم عربي RTL بالكامل.

## هيكل المشروع

│   │   ├── utils.py             حساب BMI و WHR تلقائياً

## طريقة التشغيل

### 1) تشغيل الـ Backend
احذف مجلد `backend/venv` القديم إن وُجد (كان تابعاً لنسخة سابقة)، ثم افتح Terminal داخل مجلد `backend`:

```bash
cd backend
python -m venv venv

# ويندوز:
venv\Scripts\activate
# ماك / لينكس:
source venv/bin/activate

pip install -r requirements.txt

# إنشاء قاعدة البيانات:
python manage.py migrate

# إنشاء حساب طبيب جاهز للدخول:
python manage.py seed_doctor

# تشغيل الخادم:
python manage.py runserver
```

سيعمل الـ API على: `http://127.0.0.1:8000` — وستجد صفحة دخول لوحة الإدارة مباشرة عند فتحه.

> إذا كان لديك مجلد `backend` من نسخة سابقة، شغّل `pip install -r requirements.txt` ثم `python manage.py migrate` مرة أخرى — هناك ترحيلة جديدة (`0002`) تضيف رقم الهاتف كمعرّف دخول للمريض وتاريخ الزيارة القابل للتعديل. الترحيلة آمنة على بياناتك الحالية ولا تحذف شيئاً.

بيانات دخول الطبيب الافتراضية (من `seed_doctor`):
- البريد: `doctor@mays.clinic`
- كلمة المرور: `doctor123`

### 2) تشغيل الـ Frontend
في Terminal آخر، داخل مجلد `frontend`:

```bash
cd frontend
python -m http.server 5500
```

ثم افتح المتصفح على: `http://127.0.0.1:5500`

> ملاحظة: لا تفتح ملفات الـ HTML مباشرة بنقرتين (file://) — بعض المتصفحات تمنع طلبات API من ملفات محلية. استخدم دائماً خادم بسيط كما بالأعلى.

### 3) تسجيل الدخول
- **كطبيب**: سجّل الدخول ببريدك الإلكتروني وكلمة المرور (الحساب الافتراضي أعلاه). **تسجيل الأطباء غير متاح من صفحة "حساب جديد"** — هذا مقصود لأسباب أمنية. لإنشاء طبيب إضافي:
  1. أنشئ حساب مدير: `python manage.py createsuperuser`
  2. افتح `http://127.0.0.1:8000/admin` وسجّل دخولك
  3. من قسم Users أضف مستخدماً جديداً واختر `role = doctor`
- **كمريض**: أنشئ حساباً جديداً من صفحة الدخول برقم هاتفك وكلمة مرور رقمية (4 أرقام على الأقل) — سيُنشأ رقم ملف تلقائياً ويظهر المريض فوراً في قائمة الطبيب. الدخول لاحقاً يكون **برقم الهاتف** وليس بريد إلكتروني.

## كيف تعمل البيانات
- **المريض يسجّل ويدخل برقم هاتفه** (وليس بريد إلكتروني) + كلمة مرور رقمية (PIN من 4 أرقام على الأقل). الطبيب يبقى يستخدم البريد الإلكتروني كالمعتاد. صفحة الدخول تقبل الاثنين معاً في نفس الحقل.
- استمارة التسجيل تجمع من أول لحظة: الاسم الكامل، العمر، الجنس، رقم الهاتف، المهنة، وتاريخ الزيارة (يجب أن يكون اليوم أو تاريخاً مستقبلياً — لا يمكن اختيار تاريخ ماضٍ).
- عند تسجيل مريض جديد، يُنشأ له رقم ملف تلقائي (`MAYS-0001`, `MAYS-0002`, ...).
- باقي استمارة التقييم (القياسات، التاريخ الطبي، نمط الحياة، الهدف العلاجي) يملؤها المريض لاحقاً من واجهته، ويمكن للطبيب تعديلها أيضاً.
- **BMI و WHR يُحسبان تلقائياً على الخادم** فور إدخال الوزن/الطول/محيط الخصر والورك.
- **الخطة الغذائية** (السعرات وتوزيع الماكروز) يضعها الطبيب فقط، ويراها المريض في واجهته.
- **متابعة التقدم** (جدول الوزن عبر الزيارات) يضيفها الطبيب فقط؛ يراها المريض كجدول ومخطط بياني للوزن.
- **ملاحظات الطبيب** خاصة بالطبيب فقط ولا تظهر للمريض.
- **تسجيل حساب طبيب عبر الـ API محظور بالكامل** حتى لو حاول أحدهم إرسال طلب مباشر — كل تسجيل عام ينشئ حساب "مريض" فقط بغض النظر عن أي بيانات يرسلها.

## ملاحظات أمنية للاستخدام الفعلي
هذا المشروع جاهز للتجربة والتشغيل المحلي فوراً. قبل استخدامه فعلياً مع مرضى حقيقيين، يُفضّل:
- تغيير `MAYS_SECRET_KEY` (متغير بيئة، مُستخدم في `backend/mays_clinic/settings.py`) إلى قيمة سرية خاصة بك، وتعيين `MAYS_DEBUG=0` في الإنتاج.
- استضافة الـ backend خلف HTTPS، وتحديد `ALLOWED_HOSTS` و `CORS_ALLOW_ALL_ORIGINS` بدل السماح للجميع.
- أخذ نسخ احتياطية دورية من ملف قاعدة البيانات `backend/mays_clinic.db`.
- تغيير كلمة مرور حساب الطبيب الافتراضي فور أول دخول (من `/admin` أو عبر `python manage.py changepassword doctor@mays.clinic`).

## تعديل الاستمارة أو إضافة حقول
كل حقول الاستمارة معرّفة في مكان واحد بسيط:
- الحقول في قاعدة البيانات: `backend/clinic/models.py` (class `Assessment`) — بعد أي تعديل شغّل `python manage.py makemigrations && python manage.py migrate`
- التحقق من المدخلات وتنسيق المخرجات: `backend/clinic/serializers.py` (class `AssessmentSerializer`)
- عرض النموذج في واجهة المريض: `frontend/patient/assessment.html`
- عرض النموذج في واجهة الطبيب: `frontend/doctor/patient.html` (تبويب "استمارة التقييم")
